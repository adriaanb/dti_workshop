# Get Creative!

Now that you have completed the tutorial section and explored the basics, it's time for hands-on prototyping and some creative experimentation. In this chapter, you will find some project ideas to get you started or draw **inspiration** from.

The aim is to develop practical experience **building your own prototypes** with the components available. Feel free to use any of the provided ideas and examples as a starting point. Build them as described, expand and modify them, or develop something entirely your own. 

We advise you start by building the basic version first. This helps you familiarize yourself with both the hardware and the software before taking it wherever you want.

{: .highlight }
You are encouraged to experiment, recombine code and components, and develop ideas in completely new directions. Just follow your inspiration!
