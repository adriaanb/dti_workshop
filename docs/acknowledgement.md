# Acknowledgements

## Origins

This resource builds on work originally done for the [Connected Interaction Kit](https://id-studiolab.github.io/Connected-Interaction-Kit/) at TU Delft by [Adriaan Bernstein](https://bernstein.design), [Aadjan van der Helm](https://studiolab.ide.tudelft.nl/studiolab/vanderhelm/) and [Frederick Ueberschär](https://ueberschaer.design), with contributions from [Martin Havranek](https://www.tudelft.nl/staff/m.c.havranek/).

## This Site

The DTI workshop resource is written and maintained by [Adriaan Bernstein](https://bernstein.design), including the tutorials, code examples, illustrations and wiring diagrams throughout.

The [Inspiration](inspiration/) section is an adaptation of work done for the 2025 edition by Heinrich Kortsch, who developed the project pages. Several have since been revised and extended by [Adriaan Bernstein](https://bernstein.design).

## Archived Material

The [Tiny Sorter](archive/2025/machine-learning/) module, taught in 2025 and now archived, was adapted and rewritten for the Raspberry Pi Pico by Heinrich Kortsch, based on the original [Google Tiny Sorter project](https://experiments.withgoogle.com/tiny-sorter).
